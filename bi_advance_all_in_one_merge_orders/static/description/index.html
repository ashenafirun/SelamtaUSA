Advance Merge Orders and Sync Product Category odoo app helps users to merge all orders like sale order, purchase order, delivery order, receipt, customer invoice and vendor bill. Users have different options to merge order like new order and cancel selected, new order and delete selected, merge order on existing selected and cancel other, merge order on existing selected and delete others, and sync POS and eCommerce product categories.

When there are large number of orders whether its Sales, Purchase, Delivery Order and Incoming Shipment/Receipt and Invoices, its hard to manage them. Users need to open each orders than process them one by one. Here we provide option to reduce your work, after installing our Odoo apps you can easily merge sales, purchase, delivery , Receipt and invoice in one click for same customers/suppliers. Just need to select them from tree view (you can use group by partner for easily filter) and merge them. Most important things you can still see different lines for different order on merged orders and then if you want, you can proceed it. After merge picking you can partially delivered or received it. Once picking has been merge it will create new picking and rest of other pickings get cancelled and source documents of new picking will have reference of cancelled picking, so user can easily get idea from where this new picking get created. When you merge sales, purchase order or invoice you will have multiple option to generate new orders, cancelled others and merge on existing orders, plus merge order will have reference of orders, so user can easily get idea from where this new orders get created.

Merge Sales Orders

User can see created sales orders wirh order lines.

Sales Order Merge Menu

On sales order tree view user have to select sales orders and under "Action" menu user can see "Merge Sale Orders" menu.

Sales Orders Merge Options

User have four options to merge sales orders as displayed in image bellow.

Option 1 : New Order and Cancel Selected

In merge sale orders wizard user have to select "New Order and Cancel Selected" options and click on "MERGE" button.

User can see selected orders are canceled and created new order.

User can also see that sales order line products quantity also merged.

Option 2 : New order and Delete all selected order

User can see selected orders in tree view.

On merge sales order wizard user have to select "New order and Delete all selected order" option and click on "Merge" button.

On tree view user can see selected order are deleted and created new sales order.

User can see new created sale order.

Option 3 : Merge order on existing selected order and cancel others

User can see selected orders on tree view.

On merge wizard user have to select "Merge order on existing selected order and cancel others" option, also select "Merge with" order so sales order will merged into selected orders.

User can see other orders are canceled and merged with selected orders

User can see merged orders.

Option 4 : Merge order on existing selected order and delete others

User can see selected order on tree view.

On sale order merge wizard user have to select "Merge order on existing selected order and delete others" options and aslo select "Merge with" orders.

User can see other order are deleted and merged with selected order.

User can see merged order from other orders.

Warnings

If selected orders partners are not same it will raise warning.

If selected orders state is not same it will raise warning.
