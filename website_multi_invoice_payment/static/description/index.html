Can we select the multiple invoices using this module from portal side?

Yes, multiple (different) invoices can be selected from portal side

Does the module support the custom payment accquire for paying multiple invoices

Yes, the module is tested with individual payment gateways like Stripe, Paypal and Authorize.net

Does the module provide partial payment functionality for multiple invoices?

Partial payment functionality is not available.

The module works on Odoo Enterprise, i.e. Odoo.sh and On-premises and it also works on Odoo community edition.
