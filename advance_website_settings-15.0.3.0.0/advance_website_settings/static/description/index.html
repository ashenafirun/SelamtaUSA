Manage your cart efficiently!!

You don't need to worry if you are running your website in Odoo as now you can configure the cart as you want. The module Odoo Website Cart Settings make the management of cart easy and make the webshop more user friendly. Admin is provided with different rights to manage the cart with the help of different settings.
Admin can define the minimum value of the cart which will abide the customer to make the order below the defined value. A customer can see the subtotal of his order line which is based on the product's unit price and ordered quantity. This module helps to define the page redirection which could be set either to the same page or to cart summary.

Advantages

  • Enables you to configure the setting of the cart as you want.
  • Make the Redirection as you want for Adding the Product in the cart.
  • Set the minimum order value allowed for the customers for a sales order from Odoo backend.
  • Show the subtotal of order lines in the cart as you want.
  • Showcase the cost in the cart page which offers a better experience to customers.
