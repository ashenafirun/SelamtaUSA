# Stock Remove Closest Location

Show users to pick items according to the removal sequence on normal inventory transfer.


# List of customisations
**Closest Location Removal Strategy**
- Allows user to define removal sequence on locations
- Then show users to pick items according to the removal sequence on normal inventory transfer



# Configuration
**Closest Location Removal Strategy**
- Choose the Picking Operation Type where you wish to apply the closest location removal strategy.(Go to, Inventory --> Configuration --> Warehouse Management --> Operations Types, Choose the record and checked "Remove From Closet Location?")
- Assign location sequence to Stock locations.(Go to, Inventory --> Configuration --> Warehouse Management --> Locations, Choose the record and enter "Removal Sequence" number)
