Efficient Cart Management with Website Cart Settings!

No need to worry, as now you can configure the cart as you want. The Website Cart Settings makes cart management easy and the webshop more user-friendly. The Odoo admin is provided with different rights to manage the cart with the help of different settings.
The admin can define the minimum and maximum cart values that restrict the customer from ordering products below or above the set limit. Customers can see the subtotal of their order line based on the product’s unit price and ordered quantity. The Odoo app helps define the page redirection that could be set to the same page or the cart summary.

Advantages of Odoo Website Cart Settings

  • It enables you to configure the cart settings as you want.
  • Set the redirection as you want for adding the product to the cart.
  • Setting the minimum and maximum order value allows customers for a sale order in Odoo.
  • It shows the order subtotal in the cart as you want.
  • Display the cost on the cart page that offers a better experience to customers.

Why Do You Need Website Cart Settings?

While checkout, customers sometimes increase or decrease the product quantity that doesn’t get added to the subtotal. Also, some products are sold in pairs and require a minimum of two quantities, while some have a maximum limit so every buyer gets equal quantities.
Odoo Website Cart Settings introduces the feature to add a minimum and maximum quantity configuration in Odoo. Also, it improves the user experience through a better interface. And you can set the minimum and maximum quantities from the cart settings.
